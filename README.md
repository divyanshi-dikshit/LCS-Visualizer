# LCS Visualizer (Java Swing)

A GUI-based implementation of the Longest Common Subsequence (LCS) algorithm using Dynamic Programming.

## Features
- Interactive GUI using Java Swing
- Displays DP table (Length Matrix)
- Shows Direction Table
- Backtracking visualization
- Computes LCS string

## Preview
![App Screenshot](screenshot\demo.png)

## Tech Stack
- Java
- Swing

## How it works
1. Enter two strings
2. Click "Generate LCS"
3. View DP table and result

## Complexity
- Time: O(n × m)
- Space: O(n × m)

## Applications
- Plagiarism detection
- DNA sequence matching
- Version control comparison
